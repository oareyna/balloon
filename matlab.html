What is Mastermind?

Mastermind is a code-breaking game I programmed using MATLAB. Your goal is to discover a secret combination of four colors in just 10 guesses. You might have to be a MASTERMIND in order to win!!!

How to Play

Enter four color letters to make your guess. After each attempt, you'll receive clues (black and white pegs, which aren't ordered) to help you figure out the secret code.

⚫ Black peg: Correct color in the correct position.

⚪ White peg: Correct color in the wrong position.

Use these clues to crack the code before you run out of guesses!

Download Mastermind ♡

Requires MATLAB installed on Windows.

How to Download & Play

Not sure how to get started? Follow these six simple steps!

01. Download Mastermind

Click the Download Mastermind button above to download the game.

02. Go to the Downloads Folder

Once the download is complete, click the downloads icon in the top-right corner of your browser.

Find mastermindGame.zip and click the folder icon (Show in folder). This will open File Explorer and take you to the downloaded ZIP file.

03. Extract the ZIP File

In File Explorer, select mastermindGame.zip and click Extract all.

Follow the extraction prompts and open the newly extracted folder. Keep all the game files together.

04. Launch the Game

Inside the extracted folder, locate PlayMastermind.bat.

Double-click this file to launch Mastermind using MATLAB.

05. Allow the Launcher to Run

Windows may display a warning because the launcher does not have a verified publisher.

If you trust the downloaded files, click Run to continue.

06. Start Playing!

MATLAB will open two windows: the Figure window, which displays the Mastermind board, and the Command Window, where you'll enter your guesses.

Follow the instructions in the Command Window and watch your board update with each guess!

Good luck, and have fun cracking the code! ♡
